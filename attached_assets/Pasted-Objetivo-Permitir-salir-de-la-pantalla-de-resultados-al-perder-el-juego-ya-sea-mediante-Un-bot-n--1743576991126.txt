Objetivo
Permitir salir de la pantalla de resultados al perder el juego, ya sea mediante:

Un botón que redirija al usuario al inicio.

Un temporizador (timer) que, en caso de inactividad, redirija automáticamente al inicio.

Instrucciones Detalladas
Agregar un Botón "Volver al Inicio"

Ubicación: Colocar el botón en un lugar visible dentro de la pantalla de resultados.

Funcionalidad:

Al hacer clic, el botón debe ejecutar una función que redirija al usuario al menú principal o a la pantalla de inicio.

Asegurarse de que el botón tenga un estilo claro y accesible, acorde al diseño general del juego.

Implementar un Timer Automático

Definir el tiempo: Establecer un tiempo de espera (por ejemplo, 10 segundos) tras el cual se redirigirá al usuario automáticamente.

Lógica del Timer:

Iniciar el timer al cargar la pantalla de resultados.

Si el usuario hace clic en el botón antes de que expire el timer, se debe cancelar el timer para evitar la redirección inesperada.

Opcional: Incluir una cuenta regresiva visible que informe al usuario del tiempo restante para la redirección.

Ejemplo Práctico en JavaScript
javascript
Copiar
// Suponiendo que ya se tiene la estructura HTML con un botón de ID "btnInicio"
const btnInicio = document.getElementById('btnInicio');
const tiempoRedireccion = 10000; // 10 segundos

// Función para redirigir al inicio
function redirigirAlInicio() {
    window.location.href = 'inicio.html'; // Ajustar la ruta según la estructura del proyecto
}

// Evento de click para el botón
btnInicio.addEventListener('click', () => {
    clearTimeout(timer);
    redirigirAlInicio();
});

// Iniciar timer para redirigir automáticamente
const timer = setTimeout(() => {
    redirigirAlInicio();
}, tiempoRedireccion);
Consideraciones Finales
Pruebas: Asegúrate de probar ambos métodos (botón y timer) para confirmar que funcionan correctamente en conjunto.

Adaptación: Si el entorno del juego es distinto (por ejemplo, en un framework específico o en otro lenguaje), adapta la lógica manteniendo la estructura básica de botón y timer.

Experiencia de Usuario: Considera la posibilidad de mostrar un mensaje o cuenta regresiva para informar al usuario sobre la redirección inminente.
